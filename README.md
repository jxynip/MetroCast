# Delhi Metro Ridership Analysis
Creating a mathematical prediction model on the delhi metro to analyse fluctuations in ridership in rainy weather conditions.

## Tech Stack

- Python
- Pandas
- Jupyter Notebook

## Version 1.1 31 July 2026
- Uses data from Delhi Transport Stack
- Data range from September 2024 to February 2025
- Data Cleanup done on the DMRC File
- Elementary Data analsys done to understand trends 
- No weather data has been added yet
- I do not have permission to share the raw data. However outputs can be viewed
